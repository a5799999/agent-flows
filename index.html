三種做法

差別在於要多快看到成果、要接多深的公司系統。時程為一般專案的粗估，實際依資料整理程度而定。

快速驗證

工具
Make 或 n8n 雲端版 + Claude API + Google Sheets
時程
約 1–2 週
適合
先跑一個情境給老闆或客戶看效果
限制
接 ERP、權限控管較弱

正式導入 建議起點

工具
n8n 自架在公司主機 + Claude API + 資料庫 + 簡單審核網頁
時程
約 4–8 週
適合
2–4 個情境，資料留在公司內

建議導入順序

先做最快見效、只需讀資料不需寫回系統的情境，再逐步接到產線。

PHASE 1

詢價到報價

  • Email 智慧分類回覆
  • 客戶詢價 → 報價單
  • 刀具選型推薦

需要：價格表、型錄 Excel、Email 帳號

PHASE 2

客戶溝通

  • Zalo 越文多語客服
  • 訂單交期追蹤
  • 會議紀錄自動化

需要：Zalo OA 帳號、ERP 可讀取訂單

PHASE 3

接進工廠系統

  • 品檢異常處理
  • 供應商比價採購
  • 週報自動產出、請假報帳簽核

需要：MES／量測資料、ERP 寫入權限

上線前要先定好的事

  • 哪些動作一定要人按確認（寄給客戶、報價、下單、付款）
  • 客戶資料與圖面放在哪裡、誰能看
  • Agent 的帳號只開需要的權限
  • 每次判斷都留紀錄，出錯能追
  • 成效指標：回覆時間、報價週期、漏單數

開始做真實系統，需要你提供

  • 第一個要做的情境（建議從報價開始）
  • 公司信箱是 Gmail 還是 Outlook
  • 有沒有 Zalo OA 官方帳號
  • ERP 系統名稱，以及能否用 API 或匯出 Excel
  • 一份價格表與一份客戶詢價範例（可去敏）

展示頁中的客戶、品項、數字皆為示意範例。
